**React Counter and Modal**

Простой проект на React + TypeScript, демонстрирующий счётчик и модальное окно.

**Описание**:
- **Цель:** показать основы управления состоянием в React и создание модального окна.
- **Функционал:** интерактивный счётчик с увеличением/уменьшением и модальное окно, отображающее текущее значение счётчика.

**Технологии**:
- **React**: версия 19
- **Vite**: сборка и dev-сервер
- **TypeScript**: типизация компонентов
- **Sass**: стили
